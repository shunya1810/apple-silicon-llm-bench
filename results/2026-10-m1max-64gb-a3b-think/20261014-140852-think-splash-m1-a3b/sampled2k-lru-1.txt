2.  **Core Concepts of LRU Cache:**
   - **Data Structure:** Typically uses a combination of a hash map (dictionary) and a doubly-linked list.
     - Hash map: O(1) lookups.
     - Doubly-linked list: Maintains insertion/access order (most recent at front, least recent at back).
   - **Operations:**
     - `get(key)`: If exists, move to front, return value. Else, return None/raise KeyError.
     - `put(key, value)`: If exists, update value and move to front. If not exists, add to front. If max size exceeded, remove least recent (back of list) and corresponding hash map entry.
   - **Thread-safety:** Requires synchronization mechanism. In Python, `threading.Lock` is standard. Alternatively, `collections.OrderedDict` can be used with a lock, but a custom linked list approach is more efficient and educational. I'll implement a proper doubly-linked list + dict approach with a lock.

   Actually, Python's `functools.lru_cache` exists but isn't thread-safe by default and is for functions. For a general cache, a custom implementation is better.

   Let's design a simple but robust version:
   ```python
   import threading
   from typing import Any, Optional

   class LRUNode:
       def __init__(self, key, value):
           self.key = key
           self.value = value
           self.prev = None
           self.next = None

   class LRUCache:
       def __init__(self, capacity: int):
           if capacity <= 0:
               raise ValueError("Capacity must be positive")
           self.capacity = capacity
           self.cache = {}  # key -> LRUNode
           self.head = LRUNode(None, None)  # dummy
           self.tail = LRUNode(None, None)  # dummy
           self.head.next = self.tail
           self.tail.prev = self.head
           self._lock = threading.Lock()

       def _remove(self, node: LRUNode):
           prev_node = node.prev
           next_node = node.next
           prev_node.next = next_node
           next_node.prev = prev_node

       def _add_to_front(self, node: LRUNode):
           node.prev = self.head
           node.next = self.head.next
           self.head.next.prev = node
           self.head.next = node

       def get(self, key: Any) -> Optional[Any]:
           with self._lock:
               if key in self.cache:
                   node = self.cache[key]
                   self._remove(node)
                   self._add_to_front(node)
                   return node.value
               return None

       def put(self, key: Any, value: Any):
           with self._lock:
               if key in self.cache:
                   node = self.cache[key]
                   node.value = value
                   self._remove(node)
                   self._add_to_front(node)
               else:
                   if len(self.cache) >= self.capacity:
                       # Remove least recently used (before tail)
                       lru_node = self.tail.prev
                       self._remove(lru_node)
                       del self.cache[lru_node.key]
                   new_node = LRUNode(key, value)
                   self.cache[key] = new_node
                   self._add_to_front(new_node)
   ```
   This is solid. Thread-safe due to `threading.Lock()`. O(1) operations. Handles max size.

   ```python
           self.cache.put(3, 'd')
           self.cache.put(4, 'e')  # evicts 2
           self.assertIsNone(self.cache.get(2))
           self.assertEqual(self.cache.get(4), 'e')

       def test_thread_safety(self):
           cache = LRUCache(100)
           errors = []
           def worker(key, value):
               try:
                   cache.put(key, value)
                   time.sleep(0.001)  # simulate work
                   cache.get(key)
               except Exception as e:
                   errors.append(e)

           # Run multiple threads concurrently
           keys = list(range(200))
           values = list(range(200))
           with ThreadPoolExecutor(max_workers=10) as executor:
               futures = [executor.submit(worker, k, v) for k, v in zip(keys, values)]
               for f in as_completed(futures):
                   f.result()

           self.assertEqual(len(errors), 0, f"Errors during concurrent execution: {errors}")
           # Verify cache consistency (all 100 keys should be present)
           for k in range(100):
               self.assertEqual(cache.get(k), k)
   ```
