1.  **Understand User Request:**
   - **Goal:** Create a thread-safe LRU (Least Recently Used) cache in Python.
   - **Features:** `get` method, `put` method, configurable max size.

2.  **Key Concepts & Components:**
   - **LRU Cache:** Needs to track access order, evict least recently used items when exceeding max size.
   - **Thread Safety:** Must handle concurrent reads/writes safely. Python's GIL helps with some operations, but for custom data structures, explicit locking (e.g., `threading.Lock` or `threading.RLock`) is needed.
   - **Data Structures:** 
     - A dictionary for O(1) lookups: `cache: dict`
     - A doubly-linked list (or ordered dict) for maintaining order. Python 3.7+ `dict` maintains insertion order, but for LRU we need to efficiently move items to the "most recently used" end. `collections.OrderedDict` has `move_to_end()` which is perfect for this.
   - **Operations:**
     - `get(key)`: Returns value if exists, else None. If found, move to end (MRU).
     - `put(key, value)`: Adds/updates key-value pair. If max size exceeded, remove first item (LRU). If key exists, update and move to end.
   - **Thread Safety:** Use a lock around both `get` and `put` operations. Since they might be called concurrently, a single lock is sufficient and simple.

3.  **Design Decisions:**
   - Use `collections.OrderedDict` for O(1) get, put, and move operations.
   - Use `threading.Lock` for thread safety.
   - Max size: configurable in `__init__`.
   - Return `None` for missing keys (standard behavior, but can be made configurable or return a sentinel if needed; I'll stick to standard).
   - Handle edge cases: max_size <= 0, invalid key types (dict keys must be hashable, which is standard).

4.  **Implementation Draft (Mental):**
   ```python
   import threading
   from collections import OrderedDict
   from typing import Any, Optional, Dict

   class LRUCache:
       def __init__(self, capacity: int):
           if capacity <= 0:
               raise ValueError("Capacity must be positive")
           self.capacity = capacity
           self.cache = OrderedDict()
           self.lock = threading.Lock()

       def get(self, key: Any) -> Optional[Any]:
           with self.lock:
               if key not in self.cache:
                   return None
               # Move to end (most recently used)
               self.cache.move_to_end(key)
               return self.cache[key]

       def put(self, key: Any, value: Any) -> None:
           with self.lock:
               if key in self.cache:
                   self.cache.move_to_end(key)
               self.cache[key] = value
               if len(self.cache) > self.capacity:
                   self.cache.popitem(last=False)  # Remove least recently used
   ```

   - What about the `get` returning a value that's still being modified by another thread? The lock ensures atomicity of the operation. Value types should be immutable or thread-safe, which is standard.
