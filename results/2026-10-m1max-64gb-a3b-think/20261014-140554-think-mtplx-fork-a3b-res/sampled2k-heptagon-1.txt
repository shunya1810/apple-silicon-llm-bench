2.  **Key Components to Implement:**

   - Physics Engine:
     - Ball class: position (x, y), velocity (vx, vy), angular velocity (omega), radius, mass, color, number, rotation angle (for visual spin).
     - Heptagon: center (0,0 relative to canvas center), radius, number of sides (7), rotation angle, angular velocity.
     - Gravity: constant downward acceleration.
     - Friction: linear damping (air resistance) and angular damping (friction).
     - Wall collisions: detect when ball intersects/heptagon edges, reflect velocity with restitution, account for wall rotation (tangential velocity of wall at contact point).

     - Spinning heptagon: update angle over time, recalculate edge positions each frame.
   - Rendering: update canvas items (ovals for balls, polygon for heptagon), apply rotation/number display.

3.  **Physics Details & Math:**
   - Heptagon vertices: 7 points on a circle of radius R, rotated by angle θ.
   - Ball-wall collision:
     - Find distance from ball center to each of the 7 edges.
     - If distance < ball radius, collision occurs.
     - Reflect velocity relative to wall normal.
     - Wall has tangential velocity at contact point due to rotation: v_wall = ω_hept × r_contact.
     - Relative velocity: v_rel = v_ball - v_wall.
     - Reflect v_rel along normal: v_rel_new = v_rel - 2*(v_rel · n)*n.
     - Apply restitution coefficient (e).
     - New ball velocity: v_ball_new = v_rel_new + v_wall.
     - Position correction to prevent sinking.
   - Ball-ball collision:
     - Distance between centers < 2*radius.
     - Relative velocity along collision normal.
     - Apply 1D elastic collision formula with restitution.
     - Transfer angular momentum due to friction during sliding/contact.
     - Position correction.
   - Rotation/Spin:
     - Balls have angular velocity ω.
     - Draw numbers with rotation: text rotation angle = current visual rotation.
     - Friction affects ω: decelerates ω over time, also affects ω during collisions.
   - Constraints:
     - Bounce height: restitution coefficient should be tuned so max bounce < R_heptagon, > r_ball. Probably e ~ 0.7-0.8.
     - All drop from center: initial positions slightly offset to avoid perfect overlap, or same position but different velocities? 5.  **Detailed Physics Implementation:**
   - **Time step:** dt = 1/60 s.
   - **Gravity:** vy += g * dt (g = 800 px/s^2 approx)
   - **Linear damping:** vel *= friction
   - **Angular damping:** omega *= ang_friction, angle += omega * dt
   - **Wall Collision:**
     For each edge i:
       v1 = vertices[i], v2 = vertices[(i+1)%7]
       edge_vec = v2 - v1
       normal = np.array([-edge_vec[1], edge_vec[0]])
       normal = normal / np.linalg.norm(normal)
       # Ensure normal points inward
       mid = (v1 + v2) / 2
       to_center = self.hept.center - mid
       if np.dot(normal, to_center) < 0:
           normal = -normal
       # Distance from ball to edge line
       dist = np.dot(ball.pos - v1, normal)
       if dist < ball.r and dist > -ball.r:  # actually just check if inside half-space
           # Find closest point on segment
           t = np.dot(ball.pos - v1, edge_vec) / np.dot(edge_vec, edge_vec)
           t = max(0.0, min(1.0, t))
           closest = v1 + t * edge_vec
           penetration = ball.r - dist  # if dist < r, penetration > 0
           if penetration > 0:
               # Position correction
               ball.pos += normal * penetration
               # Wall velocity at closest point
               r_vec = closest - self.hept.center
               v_wall = np.array([-self.hept.omega * r_vec[1], self.hept.omega * r_vec[0]])
               # Relative velocity
               v_rel = ball.vel - v_wall
               # Normal component
               v_rel_n = np.dot(v_rel, normal)
               if v_rel_n < 0:  # moving towards wall
                   v_rel -= (1 + ball.restitution) * v_rel_n * normal
                   ball.vel = v_rel + v_wall
                   # Add tangential friction for spin
                   tangent = np.array([-normal[1], normal[0]])
                   v_rel_t = np.dot(v_rel + (1+e)*v_rel_n*normal, tangent) # Actually, just use post-reflection vel
                   # Simplify: transfer some linear tangential vel to angular
                   ball.omega += np.dot(ball.vel - v_wall, tangent) / ball.r * 0.5
