Records with an "offline" status consistently exhibit higher sensor values than those marked "nominal" within the same data cycle. This is because the status sequence (nominal, degraded, recovering, offline, calibrating) follows the descending sensor value trend. Consequently, "nominal" records appear at the start of each 18-record cycle with the highest values (e.g., ~99-100), while "offline" records appear later in the cycle with lower values (e.g., ~50-60). For instance, Record 000000 is nominal with a sensor value of 0.0 (start of the first cycle), whereas Record 000003 is offline with a value of 82.6. Similarly, Record 000010 is nominal (42.7) while Record 000013 is offline (25.6). In terms of zones, both statuses share the same alternating A/N prefix pattern and the +17 numeric increment rule.
