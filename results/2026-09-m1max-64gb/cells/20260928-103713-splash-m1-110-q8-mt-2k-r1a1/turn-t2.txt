Records with an "offline" status consistently exhibit higher sensor values compared to those marked "nominal." This difference arises because the sensor values follow a strict descending linear trend, while the status cycles through a fixed five-state sequence. Consequently, "offline" records (the fourth in each cycle) always have higher values than "nominal" records (the first in the next cycle), which have dropped significantly. For instance, Record 000003 (offline) has a sensor value of 82.6, whereas the subsequent Record 000005 (nominal) is only 71.2. Similarly, Record 000008 (offline) reads 54.1, while Record 000010 (nominal) reads 42.7. This pattern holds for Record 000013 (offline, 25.6) versus Record 000015 (nominal, 14.2).
