Records with an "offline" status consistently exhibit higher sensor values than those marked "nominal" within the same cyclic sequence. This is because the status cycle (nominal, degraded, recovering, offline, calibrating) advances as the sensor value decreases. Consequently, "nominal" records appear at the start of each 5-record cycle with the highest values, while "offline" records appear later in the cycle with lower values.
