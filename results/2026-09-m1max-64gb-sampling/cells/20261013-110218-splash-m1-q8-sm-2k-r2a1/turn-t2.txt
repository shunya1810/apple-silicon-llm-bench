Comparing records with `status=nominal` versus `status=offline` reveals distinct differences in sensor magnitudes and zone assignments. Nominal records generally appear at the start of the five-state cycle (indices 0, 5, 10, etc.), while offline records appear at the third position in that cycle (indices 3, 8, 13, etc.). Consequently, nominal records tend to have higher sensor values than the preceding offline records in the same cycle, but lower than the following degraded/recovering/calibrating ones.

For instance, Record 000005 is `nominal` with a sensor value of 71.2 in zone N95. In contrast, Record 000003 is `offline` with a sensor value of 82.6 in zone N61. Here, the offline record has a higher sensor value than the nominal one. However, looking at Record 000015 (`nominal`, sensor 14.2, zone N85) and Record 000013 (`offline`, sensor 25.6, zone N51), the offline record again holds a higher sensor value. This pattern holds because the sensor value decreases linearly across all records; thus, an earlier record in the sequence (even if offline) will always have a higher sensor value than a later record (even if nominal). Zone prefixes for nominal records often end in odd numbers (e.g., N95, N85, N75), while offline records in the same cycle often share the same prefix but different suffixes (e.g., N61, N51, N41).
