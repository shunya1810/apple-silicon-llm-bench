Comparing offline and nominal records reveals distinct patterns in sensor values and zone assignments. Sensor values for both statuses follow the same global decreasing trend, but they occupy different phases of the sawtooth cycle because their status assignments are offset by one record. For instance, Record 000003 (offline) has a sensor value of 82.6, while Record 000004 (nominal) follows with 76.9. This offset means that at any given point in the sequence, an offline record typically has a slightly higher sensor value than the immediately following nominal record. Regarding zones, both statuses use the same rotating set of zone identifiers (e.g., A10, N27, A44), but because the zone assignment also increments or cycles independently of the status, specific zones appear in both statuses at different times. For example, zone A10 appears in nominal Record 000000 and later in offline Record 000008. Thus, while the distribution of sensor values is uniform across all statuses due to the linear decay, the temporal offset between offline and nominal records creates a consistent shift in their measured values despite shared zone pools.
