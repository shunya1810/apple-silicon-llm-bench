**`_ast_unparse.py`** provides the backing implementation for `ast.unparse()`, which converts an AST back into Python source code. It is kept in a separate module to keep the `ast` module's import time fast.

- **`Unparser`** – the core class, a subclass of `ast.NodeVisitor`. It recursively walks an AST and appends text fragments to an internal `_source` list. Its `visit()` method resets the buffer, calls `traverse()`, and returns the joined string.

  - *Buffering utilities*: `write()`, `fill()` (indentation-aware), `maybe_newline()`, `maybe_semicolon()` (for interactive mode), and the `buffered()` context manager (to use a throwaway buffer).

Together, the precedence enum, the context-manager helpers, and the per-node visitors ensure the unparser emits syntactically correct, minimally-parenthesized Python source from any supported AST.
