=====
`_ast_unparse.py` provides the implementation behind `ast.unparse()`, which converts a Python AST back into equivalent source code. It contains two main components:

**`_Precedence`** – an `IntEnum` listing operator precedence levels (from `NAMED_EXPR` down through `ATOM`). Its `next()` method returns the next-highest level or itself, enabling parenthesization decisions.

**`Unparser(NodeVisitor)`** – the core class. It recursively walks an AST and appends formatted source text to an internal `_source` list. Key mechanisms:

- **Formatting helpers** – `fill()` indents and adds a newline (or a semicolon in interactive mode); `maybe_newline`/`maybe_semicolon` conditionally separate statements; `write()` appends raw text.
- **Context managers** – `block()` emits a colon, increments `_indent`, and decrements on exit to handle nested blocks. `delimit()` wraps expressions in delimiters (e.g. parentheses). `buffered()` swaps in a temporary list for sub-expressions.
- **Precedence tracking** – `set_precedence`/`get_precedence` store a `_Precedence` per node in a dict; `require_parens` compares the current node's precedence against the context's to decide whether to add parentheses, avoiding redundant ones.
- **Docstring and type-comment handling** – `get_raw_docstring` locates a leading string constant in a module/class/function body so it's emitted as a proper docstring; `get_type_comment` reattaches `# type:` comments.
- **`visit_*` methods** – one per AST node type (Module, Expr, Import, Assign, Return, etc.) that compose the helpers above. For example, `visit_Assign` traverses each target, writes `" = "`, then traverses the value; `visit_ImportFrom` writes the module path and interleaves alias names with `", "`.

The public entry point `visit(node)` resets `_source`, calls `traverse` (which dispatches via `NodeVisitor.visit`), and returns the joined string. Together, these pieces ensure the output is valid, correctly indented, and minimally parenthesized Python source.
